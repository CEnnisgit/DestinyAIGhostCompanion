## Log Entry Format (8 Required Fields)

Per §4.3.4 of PDA-SDD:

1. **Significance** — Major/Minor + domain (Req/Design/Code)
2. **Results** — Success/Failure/Approved Modification
3. **Date** — Date and time
4. **Change Summary** — Brief summary
5. **Detailed Changes** — Full details
6. **References** — Links to SRSD requirements
7. **Issue Tracking** — Ticket number (if any)
8. **Author** — Who performed/recorded
