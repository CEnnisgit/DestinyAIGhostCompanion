### ADR-0033: Stateless Workspace Context

- Wrote and committed ADR-0033: workspace context via `X-Workspace-Id` header
- Stateless approach — no server-side session tracking for workspace context
- Default behavior: omit header → personal workspace
- Validated by middleware on every request via derived access query

### Phase 3B: Authentication — SPEC COMPLETE ✅

- Resolved design questions Q1-Q5 (research doc: `PHASE_3B_Research.md`)
- Rewrote stale `Auth/README.md` (was referencing old NestJS stack)
- Wrote 4 new specs in `DDD/ModuleDesign/Auth/`:
  1. **AuthenticationService.md** — login/refresh/logout flows, workspace resolution middleware, `refresh_tokens` table schema
  2. **AuthContext_VO.md** — value object carrying identity + workspace context through request handlers
  3. **TokenStrategy.md** — JWT access token (15m) + opaque refresh token (7d, HttpOnly cookie)
