## 🏗️ What We Built (Feature Summary)

We successfully implemented **Pipeline A (PAD Bootstrap)**, a high-performance ETL worker written in Rust designed to prepopulate the system with city-wide building identities from NYC Planning's Property Address Directory (PAD).

### Key Accomplishments:
1. **Rust Worker (`apps/pad-ingestion`)**: Built a memory-efficient CLI tool that processes the 1.1M+ row PAD dataset in seconds using zero-copy deserialization where possible.
2. **Multi-Pass Architecture**:
   - **Pass 1:** Loads PAD Condo/Billing features into an in-memory BBL cache.
   - **Pass 2:** Processes address ranges, applies tie-breaker logic to resolve the `primaryBbl` for each BIN, and determines anomalies.
   - **Pass 3:** Batched upserts to PostgreSQL for canonical buildings and streams addresses to the `building_addresses` search index.
3. **Provenance & Timeline Tracking**:
   - Implemented `building_events` table. Every run of the pipeline diffs the existing database state against the incoming PAD payload. Only modified fields generate a JSON `changed_fields` event.
   - Added `pad_last_seen_at` (updated on every run) and `created_from_source` tracking to `buildings`.
4. **Authority-per-VO & Diagnostics Validation**:
   - **BIN VO**: Enforces 7-digit bounds (rejects 6-9 boroughs and all-zeros), quarantines failures, issues soft warnings for temp/dummy BINs.
   - **BBL VO**: Strong invariants (block >= 1, lot >= 1, valid borough), explicitly rejects generic sentinels.
   - **Address VO**: Normalizes display strings (uppercase, whitespace collapse) for the search index.
   - **Diagnostics**: Implemented the `Ingestion_Diagnostics.md` specification exactly. `ERROR`-severity rows (broken identity) are dumped raw into `quarantined_rows`. `WARN`-severity rows (broken BBL, tie-breakers) populate `import_anomalies`.

### Technical Decisions Impacting Architecture:
- Kept the PAD worker outside of the core NestJS API since it is an asynchronous, batch ETL task with highly specific memory demands.
- Used `sqlx` in Rust for type-safe, compile-time query verification against the actual Drizzle schema.
