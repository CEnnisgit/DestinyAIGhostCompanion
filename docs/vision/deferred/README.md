# Deferred Concepts

This folder captures product and architectural concepts that have been **discussed, agreed upon at a high level, but explicitly deferred** to a future phase.

## What Goes Here

- Features that were designed enough to capture the "what" and "why" but are NOT being built yet
- Concepts that emerged during architectural discussions and need to be preserved
- Ideas that influence current design (e.g., "we're deferring Teams, but the Workspace model was designed to accommodate them")

## What Does NOT Go Here

- Active features → `docs/vision/`
- Architectural decisions → `docs/adr/`
- Implementation specs → `docs/2-during-implementation/DDD/`
- Cross-cutting design patterns → `docs/design/`
