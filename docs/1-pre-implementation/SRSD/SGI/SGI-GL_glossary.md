# SGI-GL: Glossary

> **Code:** `SGI-GL`
> **Category:** General Info

## Terms & Definitions

| Term | Definition |
|------|------------|
| **LL152** | NYC Local Law 152: Requires periodic gas piping inspections for buildings. |
| **GPS1** | Gas Piping System Inspection Report (Form GPS1) — submitted to building owner. |
| **GPS2** | Gas Piping System Certification (Form GPS2) — filed with NYC DOB. |
| **LMP** | Licensed Master Plumber — authorized to sign/seal LL152 certifications. |
| **Plumber / Technician** | Field worker who performs the physical inspection. |
| **DOB** | NYC Department of Buildings. |
| **Community District** | Geographic subdivision of NYC determining inspection cycle (A, B, C, D). |
| **Inspection Cycle** | 4-year rotation by Community District for LL152 compliance. |
| **Packet** | The complete deliverable: GPS1 + GPS2 + supporting photos/notes. |
| **Dispatch** | Assigning a job to a technician with a scheduled time window. |
| **Handoff** | The submission of completed inspection data from Plumber to LMP. |
