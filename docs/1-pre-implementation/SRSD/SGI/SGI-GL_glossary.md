# General Information: Glossary (SGI-GL)

- **Ollama**: An open-source application that allows users to run Large Language Models (LLMs) locally on their own hardware.
- **Bungie.net API**: The official REST API provided by the developer of Destiny 2 for accessing player state.
- **Vault**: The global repository in Destiny 2 where players can store items shared amongst all their characters.
- **Manifest**: The massive, serialized SQLite database containing all item definitions, names, hashes, and lore available in Destiny 2.
- **Instance ID**: The unique identification number given to a specific instance of a dropped weapon or armor piece in the game.
- **STT (Speech-to-Text) / TTS (Text-to-Speech)**: Modules used to convert voice to text and vice-versa.
