# Non-Functional Requirements: Usability (SNFR-U)

## Hands-Free Definition (SNFR-UEU)
- **`SNFR-UEU-01`**: Core operations must necessitate absolute zero clicks. A user whose hands are on a mouse, keyboard, or controller must be able to trigger the Ghost and execute an item swap purely through audio.
- **`SNFR-UEU-02`**: The system must provide overt auditory cues (chimes, spoken TTS confirmations) so that the user does not need to look at a second screen to confirm their action succeeded.

## Accessibility (SNFR-UA)
- **`SNFR-UA-01`**: The web and iOS clients must offer a visual chat-log of the interactions for users who prefer to type, or for deaf/hard-of-hearing users who require a text-based confirmation of the Ghost's outputs.
