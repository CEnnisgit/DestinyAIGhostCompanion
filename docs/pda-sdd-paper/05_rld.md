# §4.3.2: Resources List Document (RLD)

The RLD empowers project managers and stakeholders to assess capabilities and establish a solid foundation for the pre-implementation stage.

## Structure

```
RLD
├── Human Resources
│   ├── Summary
│   │   ├── Job Title
│   │   └── Sum (count)
│   └── Details
│       ├── Name
│       ├── Job Title
│       ├── Experience
│       ├── Qualification
│       └── Hourly Cost
│
└── Equipment
    ├── Hardware
    │   ├── Computers
    │   ├── Servers
    │   └── Storage Devices
    └── Software
        ├── Development Environment
        ├── Version Control System
        ├── Database Management System
        ├── Operating System
        ├── Design Tools
        ├── Testing Tools
        ├── Deployment Tools
        ├── Project Management Tools
        ├── Communication Tools
        ├── Documentation Tools
        └── Virtual Machines
```

## Sections

### Human Resources

Two sub-sections:
1. **Summary** — Job titles and corresponding quantities
2. **Details** — Individual team members: names, job titles, experience, qualifications, hourly rates

### Equipment

Categorized into hardware and software. Within each category, three key elements are identified: total equipment and equipment types.
